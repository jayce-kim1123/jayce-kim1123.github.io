## 오늘의 카테고리

고대 서양철학

## 질문

헤라클레이토스는 만물이 끊임없이 변한다(만물유전, panta rhei)고 했고, 파르메니데스는 진짜 존재는 변하지 않는다고 했다. 끊임없이 변한다면 어제의 나와 오늘의 나는 정말 같은 '나'일까, 아니면 그저 연속적으로 보일 뿐인 서로 다른 존재들의 연쇄에 불과한 걸까?

## 대화 요약

```
claude: 끊임없이 변한다면, 어제의 나와 오늘의 나는 같은 '나'일까, 아니면 연속적으로 보이는 서로 다른 존재들의 연쇄일까?
나: 테세우스의 배로 보면 될 것 같아. 물리적 실체(형이하학) 기준으로는 어제의 나와 오늘의 나는 다르지만, 역사적 연속성(형이상학) 기준으로는 같아. 후자가 더 편리한 기준이야.
```

이건 철학자 피터 기치가 말한 "상대적 정체성(relative identity)" 이론과 통한다. 기치는 동일성이 절대적으로 성립하는 사실이 아니라 항상 어떤 기준에 상대적으로만 성립한다고 봤다 — "같은 사람으로서는 같지만 같은 물질 덩어리로서는 다르다"는 식으로, 질문 자체에 "무엇으로서 같은가"를 끼워 넣어야 한다는 것이다.

```
claude: 그런데 물리적 기준도 어느 한 순간의 단면이 아니라, 과거부터 미래까지 이어지는 4차원 전체(세계선)로 보면 결국 안 변하는 거 아닐까?
나: 맞아, 그렇게 보면 물리적 기준도 결국 안 변해. 둘을 통합할 수 있겠네.
```

이게 바로 데이비드 루이스가 옹호한 퍼듀어런티즘(perdurantism)이다. 사물을 한 순간에 존재하는 3차원 대상이 아니라, 시간적 부분들을 전부 합친 4차원 세계선 전체로 보는 관점이다. 이 관점에서는 "어제의 나"와 "오늘의 나"가 애초에 같은 하나의 세계선의 서로 다른 시간적 부분일 뿐이라서, 물리적 기준과 역사적 연속성 기준이 하나로 합쳐진다.

```
claude: 그럼 내 기억을 그대로 복사해 업로드한 복제 인간은 나일까?
나: 아니, '헤리티지(유산)'가 안 넘어가. 복제본은 내 과거의 실제 시간적 부분들을 갖지 못하고, 창조된 시점부터 완전히 새로운 세계선이 시작되는 거야.
```

이 지점에서는 질적으로 똑같아도 "이것"이라는 개별적 사실 자체가 다르면 다른 개체라는 둔스 스코투스의 이것임(haecceitas) 개념이 소개됐다. 기억과 성격이 완전히 같아도, 그 세계선이 실제로 과거와 물리적으로 이어져 있었는지는 또 다른 차원의 사실이라는 것이다.

```
claude: 순간이동처럼 몸을 분해하고 다른 곳에서 재구성하는 경우는 어때? 그 사이에 물리적 연속성이 끊기는데.
나: 경쟁하는 분기가 없다면, 그 시간적 공백은 괜찮아.
```

```
claude: 그런데 장치가 오작동해서 원본도 남고 복제본도 하나 더 생기는 분기 상황이라면?
나: 장치의 물리적 기록이 항상 어느 쪽이 원본이고 어느 쪽이 복제인지 구분해줄 거야.
claude: 그 기록이 나중에 삭제되면?
나: 기록이 삭제돼도, 과거에 실제로 있었던 물리적 사실 자체는 영원히 남아 있어.
```

이건 과거·현재·미래가 모두 동등하게 실재한다고 보는 영원주의(블록 우주론)와 맞닿아 있다. 기록이라는 "증거"가 없어져도, 사건 자체가 블록 우주 어딘가에 영원히 새겨져 있다는 그림이다.

```
claude: 근데 그건 파르메니데스가 말한 '불변하는 하나의 전체'를 블록 우주 전체 수준에서 되살리는 셈 아닐까?
나: 완전한 영원주의는 아니야. 미래는 아직 결정되지 않았으니까, 그보다는 '성장하는 블록 우주' 쪽에 더 가까워.
```

이 정정은 철학자 C. D. 브로드가 제시한 성장 블록 우주론(growing block universe)과 정확히 일치한다. 과거와 현재는 고정되어 실재하지만 미래는 아직 존재하지 않고 계속 새로 "자라난다"는 중간적 입장이다.

```
claude: 특수상대성이론에서는 보편적인 '지금'이라는 게 없다고 하는데, 그럼 어느 시점에서 과거가 '고정'된다고 할 수 있어?
나: 하나의 보편적인 경계선을 주장한 적은 없어. 각자의 세계선이 자기만의 국소적인 '지금'을 가지면 되는 거야.
```

이는 물리철학자 호워드 스타인이 제시한 "점 상대적 생성(point-relative becoming)" 개념과 같은 구조다. 우주 전체에 공유되는 단일한 "지금"은 없어도, 각 세계선이 자기 자신의 관점에서 과거를 고정시켜 나가는 것은 상대성이론과 충돌하지 않는다는 것이다.

```
claude: 그런데 공간적으로 완전히 분리된 두 분기 사이엔 시간적 순서 자체가 없을 수도 있잖아. 그럼 뭐가 원본이고 뭐가 복제인지 어떻게 정해?
나: 원본과 복제의 구분은 시간 순서에서 나오는 게 아니야. 복제 행위 자체의 인과적 방향성에서 나와 — 원본 신체에서 장치의 메모리로 정보가 연속적으로 이동하는 과정과, 그 메모리를 복사해서 새로운 몸에 쓰는 행위 사이에는 구조적인 비대칭이 있거든.
```

```
claude: 그 비대칭마저 완전히 없는, 진짜로 대칭적인 복제라면 어떻게 돼?
나: 그 경우엔 형이하학적으로 둘 다 나라고 인정할 수밖에 없어.
```

이 지점은 데릭 파핏이 "분열(fission)" 사례로 도달한 결론과 정확히 같다. 뇌를 둘로 나눠 각각 다른 몸에 이식하면, 엄격한 의미의 동일성(한 사람=한 사람)은 깨지지만, "생존"이라는 개념은 배타적이지 않게 — 즉 둘 다에게 — 유지될 수 있다는 것이다. 파핏은 바로 이 지점에서 "엄격한 동일성보다 생존 여부가 우리에게 중요한 것"이라고 결론 내렸다.

```
claude: 그래서 결국 동일성이란 뭐라고 정리할 수 있을까?
나: 동일성은 고정된 하나의 사실이 아니라, 기준에 따라 하나이거나 여럿일 수 있는 유동적인 개념이야. 여기까지 하자.
```

## 핵심 개념 정리

- **피터 기치의 상대적 정체성**: 동일성은 절대적 사실이 아니라 언제나 "무엇으로서 같은가"라는 기준에 상대적으로만 성립한다는 이론.
- **퍼듀어런티즘(perdurantism)**: 데이비드 루이스 등이 옹호한 관점으로, 사물을 한 순간의 3차원 단면이 아니라 시간적 부분들의 합인 4차원 세계선 전체로 보는 입장.
- **둔스 스코투스의 이것임(haecceitas)**: 질적으로 완전히 같아도 "이것"이라는 개별적 사실 자체가 다르면 서로 다른 개체라는 개념.
- **영원주의와 성장 블록 우주론**: 영원주의는 과거·현재·미래가 모두 동등하게 실재한다고 보고, C. D. 브로드의 성장 블록 우주론은 과거·현재는 고정되어 실재하지만 미래는 아직 존재하지 않는다는 중간적 입장이다.
- **호워드 스타인의 점 상대적 생성**: 상대성이론 아래에서는 우주 전체에 공유되는 단일한 "지금"이 없지만, 각 세계선이 자기 관점에서 국소적으로 "지금"을 고정해 나갈 수 있다는 개념.
- **데릭 파핏의 분열(fission) 사례**: 뇌를 둘로 나눠 각각 다른 몸에 이식하는 사고실험. 엄격한 동일성은 깨지지만 "생존"은 비배타적으로 유지될 수 있다는 결론으로 이어진다.

## 오늘의 결론

헤라클레이토스식 변화와 파르메니데스식 불변 사이에서, 대화는 테세우스의 배 비유로 시작해 물리적 실체 기준과 역사적 연속성 기준을 나눈 뒤 퍼듀어런티즘으로 둘을 하나로 통합했다. 기억 복제·순간이동·분기 같은 사고실험들을 거듭 변형해 가며 검증한 끝에, 과거의 물리적 사실은 영원히 남아있지만 미래는 아직 정해지지 않은 성장 블록 우주에 가깝다는 입장을 정리했고, 상대성이론의 동시성 문제에도 "국소적 지금"으로 대응했다. 마지막으로 완전히 대칭적인 복제의 경우에는 엄격한 동일성을 포기하고 둘 다 나로 인정할 수밖에 없다는 데 동의하며, 동일성이란 고정된 하나의 사실이 아니라 기준에 따라 하나이거나 여럿일 수 있는 유동적인 개념이라는 정리로 대화를 마무리했다.
